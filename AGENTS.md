# Инструкции для агентов

## Структура проекта

- Production-проект расположен в `src/YandexContestClient`.
- Основной клиентский API и модели в `src/YandexContestClient/Client` сгенерированы Kiota. Скрипт `update-client.sh` удаляет этот каталог и создаёт его заново; не вноси туда ручные изменения, которые должны сохраниться при генерации.
- Код интеграции, авторизации и регистрации DI находится вне каталога `Client`.
- Тестовых проектов сейчас нет. Не добавляй тестовые проекты без явного запроса пользователя.

## Сборка и пакеты

- Решение: `YandexContestClient.slnx`.
- Целевая платформа и общие свойства сборки заданы в корневом `Directory.Build.props`.
- Централизованные версии NuGet-пакетов находятся в `Directory.Packages.props`. В `PackageReference` не указывай версии.
- `NuGet.config` очищает унаследованные источники и оставляет nuget.org для восстановления зависимостей. GitHub Packages используется CI только для публикации готового пакета.
- Для проверки сборки используй `dotnet restore YandexContestClient.slnx` и `dotnet build YandexContestClient.slnx --no-restore`.
- При перемещении проекта обновляй пути в solution, `.github/workflows/dotnet.yml` и `update-client.sh`.
